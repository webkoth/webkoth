# Кампании Директа для лендингов webkoth.com

Четыре поисковые кампании и одна РСЯ под страницы `/kontur`, `/it-director`, `/agent`, `/finance`.
Семантика из Wordstat (август 2026), тексты из копирайта лендингов. Основание:
`docs/superpowers/specs/2026-09-02-chetyre-lendinga-pyat-kampaniy-design.md`, секция 10, с одним
отличием: две финансовые кампании из спеки объединены в одну (решение владельца 2026-09-03),
группы первички ведут на `/finance?p=pervichka`, группы отчётности на `/finance?p=otchet`.

| Файл | Что это |
|---|---|
| `kampanii.mjs` | Источник истины: кампании, группы, фразы, минус-слова, объявления, быстрые ссылки, уточнения |
| `build.mjs` | Генератор файлов импорта и проверка лимитов Директа. Запуск: `node marketing/direct/build.mjs` |
| `dist/*.xlsx` | Шесть файлов для Директ Коммандера, один файл = одна кампания |
| `dist/summary.md` | Сводка по группам для сверки после импорта |
| `images/` | Баннеры для РСЯ, по три формата на страницу (рендер из `content-factory`) |

Файлы собраны по официальному XLSX-шаблону Директа (`direct_example.xlsx`, генератор скачивает
его сам в `ref/`): лист «Тексты» с шапкой «Тип кампании» и «Минус-фразы на кампанию» в строках
7–9, заголовок таблицы в строках 10–11, данные с 12-й строки; листы «Регионы» и «Словарь значений
полей» из шаблона без изменений. Тип кампании «Единая перфоманс-кампания», тип объявления
«Комбинаторное»: с июля 2026 новые текстово-графические объявления через импорт не создаются,
комбинаторное объявление само перебирает сочетания заголовков и текстов. В каждой группе одно
объявление: четыре заголовка (два длинных, два коротких) и два текста. Все строки фраз главного
объявления помечены «-», как в шаблоне.

Первая версия была в CSV по старому примеру Коммандера, и импорт потерял регион и колонку
«Тип объявления». Если такой файл уже импортирован, удалить кампанию в Коммандере до отправки
на сервер и импортировать XLSX заново.

## Что делает файл, а что нет

В файле: группы, фразы, автотаргетинг (строка `---autotargeting`), объявления, ссылки с UTM,
отображаемая ссылка, регион «Россия», быстрые ссылки на секции страницы, уточнения,
минус-слова на уровне группы (общий список плюс список кампании), стартовые ставки.

Не в файле, задаётся в Коммандере после импорта: стратегия и недельный бюджет, счётчик Метрики
и цели, расписание показов, корректировки ставок, категории автотаргетинга, запрещённые
площадки РСЯ, изображения для РСЯ. Список ниже.

## Импорт в Директ Коммандер

1. Коммандер → войти под аккаунтом с Директом → «Кампании» → «Импорт» → «Из файла».
2. Выбрать `dist/kontur.xlsx`. Режим «Создать новую кампанию».
3. В окне сопоставления проверить: «Тип объявления» = Комбинаторное, «Регион» = Россия,
   «Заголовок 1…4» и «Текст 1…2» в комбинаторном блоке. Флажок «Установить регион для всех»
   не нужен.
4. Повторить для остальных пяти файлов. Название кампании Коммандер спрашивает при импорте,
   брать из ячейки A6 файла (например «Поиск · Контур 1С и маркетплейсы»).
5. Пройти по настройкам кампаний из следующего раздела, затем «Отправить на сервер».
6. После отправки открыть каждую кампанию в веб-интерфейсе Директа и проверить, что фраз,
   групп и объявлений столько же, сколько в `dist/summary.md`, а объявления на модерации.

Кросс-минусовка: в Коммандере выделить все поисковые кампании → «Фразы» → «Оптимизировать
фразы» → «Кросс-минусовка». Делать после импорта, до отправки на сервер.

## Настройки кампаний после импорта

Общее для всех шести кампаний:

| Настройка | Значение |
|---|---|
| Счётчик Метрики | 112267661 |
| Ключевые цели | `lead_sent` (основная), `quiz_result`, `quiz_start` |
| Разметка ссылок для Метрики | включить (yclid), UTM в ссылках уже есть |
| Регион | Россия; корректировка «Москва и область» +30%, «Санкт-Петербург и область» +15% |
| Расписание | Пн–пт 8:00–20:00, выходные выключены (60 часов в неделю, минимум Директа 40) |
| Корректировки по полу, возрасту, устройствам | не ставить первые 3–4 недели |
| Минус-слова кампании | уже на уровне групп; дополнительно вставить общий список из `kampanii.mjs` (`NEGATIVES_COMMON`) в минус-фразы кампании |

Поиск, четыре кампании:

| Настройка | Первые 3 недели | После 3 недель |
|---|---|---|
| Стратегия | «Максимум конверсий», оплата за клики, цель `quiz_result` | та же, цель `lead_sent`; оплата за конверсии, когда есть 10 заявок в неделю |
| Недельный бюджет | по таблице ниже | пересчитать по фактической цене заявки |
| Автотаргетинг | оставить «целевые» и «узкие», снять «широкие», «альтернативные», «сопутствующие» | пересмотреть по отчёту поисковых запросов |
| Ставки | стартовые 30 ₽ в файле, автостратегия их игнорирует | |

РСЯ, одна кампания на четыре группы:

| Настройка | Значение |
|---|---|
| Стратегия | «Максимум конверсий», оплата за клики, цель `quiz_start` |
| Недельный бюджет | по таблице ниже, поднимать только после первых заявок |
| Ограничение частоты | не более 3 показов на человека за 7 дней |
| Запрещённые площадки | внешние мобильные сети и игры: `com.*` приложения, Smaato, MobFox, Inner-active, BidSwitch, dsp.*; после первой недели добавить площадки с CTR выше 2% без конверсий |
| Изображения | в каждой группе минимум три: 1:1 от 1000×1000, 4:3 от 1000×750, 16:9 от 1080×607, JPG или PNG до 10 МБ. Загрузить в Коммандере в «Изображения», привязать к объявлению группы |
| Видео | не обязательно, Директ сгенерирует из картинок |

Картинки для РСЯ: не стоковые. Рабочие варианты: скриншот карточки кейса со страницы
(«Болело / Стало»), экран квиза с вердиктом, схема «1С ↔ площадки ↔ отчёт» на светлом фоне.
Текст на картинке не больше 20% площади.

## Бюджет и волны

Доля от общего месячного бюджета, недельный бюджет = месячный × доля / 4.3:

| Кампания | Доля | При 60 000 ₽ в месяц, в неделю |
|---|---:|---:|
| Поиск · Контур 1С и маркетплейсы | 25% | 3 500 ₽ |
| Поиск · ИТ-директор на аутсорсе | 20% | 2 800 ₽ |
| Поиск · Финансовый контур | 30% | 4 200 ₽ |
| Поиск · ИИ-агенты для бизнеса | 15% | 2 100 ₽ |
| РСЯ · Четыре услуги | 10% | 1 400 ₽ |

Волны по спеке: сначала контур и ИТ-директор, через две недели финансовая и РСЯ, через
четыре недели агенты. Бюджет не запущенных кампаний в это время идёт первой волне.
В финансовой кампании автостратегия сама распределит бюджет между группами первички и
отчётности; если одна из них съедает всё, ограничить её ставки корректировкой на группу.

Правило остановки на кампанию: 40 кликов без старта квиза или 80 кликов без заявки, пауза
и переписывание объявлений, не страницы. Порог цены заявки назначается после двух недель
данных. Раз в неделю строка результатов в `business-os/execution/`.

## Еженедельный разбор

1. Директ → «Статистика» → «Поисковые запросы» по каждой кампании: запросы без конверсий и
   не про услугу в минус-слова группы; новые целевые запросы добавить фразами в `kampanii.mjs`.
2. Метрика → отчёт по целям с разбивкой по UTM: `utm_campaign` и `utm_content` показывают
   кампанию и группу, `utm_term` фразу. Сравнить `quiz_start` → `quiz_result` → `lead_sent`.
3. РСЯ: отчёт по площадкам, исключить площадки с кликами без `quiz_start`.
4. Комбинаторные объявления: в интерфейсе Директа видно, какие заголовки и тексты выигрывают;
   слабые заменить в `kampanii.mjs`, пересобрать и импортировать в исходную кампанию.
5. Изменения фиксировать в `kampanii.mjs` и пересобирать `dist/`, чтобы файл оставался
   источником истины, а не Коммандер.

Ретаргетинг: отдельная группа в РСЯ по сегменту Метрики «достиг `quiz_start`, не достиг
`lead_sent`». Запускать, когда в сегменте накопится 150–200 человек, раньше охвата не будет.

## Ограничения формата, о которых стоит помнить

- Один XLSX = одна кампания. Ячейка A6 это название, E9 минус-фразы кампании (общий список плюс список кампании), «Минус-фразы на группу» только у групп со своим списком.
- Динамический параметр `{keyword}` в ссылке подставляет Директ. В РСЯ вместо него `{source}`, площадка.
- Строка `---autotargeting` в каждой группе включает автотаргетинг; на поиске он обязателен, категории сужаются в Коммандере.
- Изображения через файл не загружаются, только ссылки на уже загруженные в аккаунт.
- Импорт «в исходную кампанию с перезаписью» удаляет в Коммандере всё, чего нет в файле. Для правок использовать «в выбранную кампанию» или править `kampanii.mjs` целиком.
